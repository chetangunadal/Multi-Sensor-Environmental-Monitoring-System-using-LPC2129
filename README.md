# Multi-Sensor-Environmental-Monitoring-System-using-LPC2129
Multi-Sensor Environmental Monitoring System using LPC2129 to monitor temperature, light, soil moisture, and water detection. The system uses LM35, LDR, soil moisture, and water sensors with ADC/GPIO interfacing. Sensor data is displayed on a 16×2 LCD and UART terminal, with LED and buzzer indications for abnormal conditions.
